# 20 — Acceptance criteria (founder-facing)

The rewrite is done when every line holds:

1. **Parity:** Phase-4 audit of [01-parity.md](01-parity.md) all PASS/INTENTIONAL; visual gallery shows existing profiles pixel-equivalent across all 9 themes.
2. **Static:** second request to a profile serves from cache with zero API/DB calls; publish→fresh <10s; nothing regenerates on a timer.
3. **Fast:** every [15-performance.md](15-performance.md) budget met, measured, recorded. CLS = 0 everywhere.
4. **Auth:** Google, GitHub, email OTP, and passkey login all work; the OTP email's magic link autofills and auto-submits; login↔signup morphs with no dead ends; hosted email via Resend from `auth@mail.kytelink.com` (SPF/DKIM/DMARC verified); self-host works with console/SMTP.
5. **Onboarding:** a fresh signup reaches a LIVE page in under 60 seconds (slug + prefilled avatar, links skippable) — measured by the `signup_to_live_ms` event.
6. **Orgs & teams:** one account owns multiple orgs/kytes and switches instantly; an org member with ALL access loses everything via one-click revoke; SELECTED access grants exactly the chosen kytes; the 5-role matrix holds under test (MANAGER can change domains/username, EDITOR provably cannot publish, VIEWER cannot edit or see analytics, last-owner guards hold); invites require explicit acceptance with strict email match; kytes transfer between orgs with grants purged; up to 3 scheduled snapshots fire within 60s of target through moderation; draft preview links gate behind their 6-digit passcode, render drafts, and revoke cleanly; the audit log records every listed action; DB-stored limits (10 kytes/org, 10 people/org, 3 owned + 7 joined orgs per user, 3 schedules, 5 preview links, 250MB org storage) trigger the contact-Aleem modal and are raisable from admin. **Simplicity holds: a solo user completes signup→publish→edit→analytics without ever seeing a team/org concept.**
7. **Uploads:** every image upload offers crop/zoom/readjust, shows real byte-level progress percentages then an optimizing state, and produces optimized main + LQIP outputs; upload bytes go direct to the bucket, never through the API server.
8. **Analytics:** zero Postgres writes on the view path; beacons land in ClickHouse; counts start fresh at launch (legacy analytics wiped by design); `grep -ri posthog` returns nothing.
9. **Moderation:** planted phishing profile suspended <60s, visible + reversible in admin; **suspension is a full read-only lockdown** — the editor shows the locked state, every mutation returns `KYTE_SUSPENDED`, quarantined images 404 off the CDN, and admin approve restores everything; **the seed sweep reviews every existing profile pre-launch and known spam launches already suspended (images dark too)**; the admin suspended view searches and filters by tripped signal (sus links / names / redirect targets / email domains); `MODERATION_PROVIDER=none` hides the feature entirely.
10. **Admin:** users / conversion / top kytes / suspended / storage-per-kyte each reachable in ≤4 clicks; the Live view shows current visitors, views/min, and signups today with ≤10s freshness; org limits editable in place; worker failures and moderation fail-opens surface as in-dashboard alerts (the platform never emails the admin); open abuse reports are actionable from the moderation view.
11. **Design:** Inter + token palette everywhere; landing redesigned per [12-landing.md](12-landing.md); framer-motion vocabulary applied per [14-design.md](14-design.md) (`prefers-reduced-motion` respected; zero motion-library code in the profile bundle); the 3 new themes ship alongside the pixel-frozen legacy 9; responsive matrix clean 360→1920; keyboard + screen-reader passes on profile, auth, editor, invites happy paths; files follow [23-conventions.md](23-conventions.md) with no narration comments.
12. **Owned assets:** `packages/cdn` serves locally in dev, syncs to the bucket on main, and no page loads images from third-party hosts.
13. **Marketing site:** six feature pages + three use-case pages live with custom mockups (real components, not screenshots); `/legal` hub + Terms + Privacy replace the PDFs; the proper footer links it all (incl. the `/report` abuse form, whose submissions land in the admin queue); every page has unique metadata and is in the sitemap; legal text flagged for founder review.
14. **Agent mode:** `pnpm agents` boots the port+1000 set; `agent@kytelink.dev` (OTP `000000` or dev-login) reaches the editor and `agent-admin@kytelink.dev` reaches admin in under a minute; `AGENT_MODE=true` in production refuses to boot; root `CLAUDE.md` documents it all.
15. **No bugs:** all critic/chaos findings closed or founder-waived; every [17-quality.md](17-quality.md) suite green; error-state checklist complete.
16. **Self-host:** fresh clone → compose → README → working instance (MinIO, console email, no moderation) in <15 min; the repo ships a simple README + full `SELF-HOSTING.md` + commented `.env.example` per [25-selfhost.md](25-selfhost.md); **tiered env validation holds** — boot refuses without a database, boots with one warning and analytics cleanly off without ClickHouse, and with the whole image concept cleanly off without S3 (no broken buttons, one calm card per disabled surface).
17. **Seed:** full run against the legacy fixture DB prints 100% PASS on the verification suite; delta mode demonstrated; `LAUNCH-RUNBOOK.md` is complete enough for the founder to execute the real seed + DNS flip alone within the ~15-min downtime window.
18. **Type-safe & DRY:** strict typecheck green; zero `any`/`@ts-ignore`; ProfileView exists exactly once; permission matrix exists exactly once.
19. **Imports:** onboarding and the editor import links from Linktree, Beacons, and Bio.link (proven against fixture pages) and from any URL via AI when `OPENAI_API_KEY` is set; imports are proposals the user confirms — nothing lands in a draft unreviewed.
20. **Growth loop measured:** the profile watermark links to `kytelink.com/?ref={username}`, fires `watermark_click`, and the admin funnel shows the % of signups attributed to it.
